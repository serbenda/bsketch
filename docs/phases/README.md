# Phases

Each block of work has a phase file `PNN-short-title.md` created with `/new-phase` from [`_template.md`](_template.md).

- A phase must fit in **one reviewable PR**. If it doesn't, split it in two.
- The **plan is approved before** writing code.
- The **Result** section is filled in on closing (`/close-phase`) and is the project's history: [STATE.md](../STATE.md) only summarizes the latest ones.
- Phases are never deleted: dropped ones stay marked ⛔ with the reason.
