# Support

bsketch is made and maintained by one person, as a personal project. Its use is governed by the [LICENSE](LICENSE).

## Which versions get fixes
- **Only the latest version** gets fixes, security ones included: the web version at https://bendi.dev/bsketch/
  is always the latest; the portable file and the desktop apps are updated by downloading the latest release.
- After 2.0.0, changes come as **2.0.x** (fixes) and **2.x** (small improvements that keep everything working).

## Your drawings
- Every `.sketch` file saved by 1.0.0 or later opens in every later version: [the format and its promise](docs/FORMAT.md).
- Drawings kept in the browser stay in that browser only: save them as files to keep a copy.

## Reporting a problem
- A security problem: privately, as [SECURITY.md](SECURITY.md) says.
- Anything else: an issue on GitHub, with the browser or app, the steps, and if you can, the file.
